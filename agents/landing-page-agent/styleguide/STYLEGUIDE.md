# Corporate Landing — style guide

A clear, confident style for company and product landing pages. Calm neutral surfaces, one brand colour used with intent, generous whitespace, and content that always sits in a centred container. The system supplies structure, type and spacing; each site supplies its own brand.

This is a visual language, not a page template. It defines how things look. Which sections a page has, and how each is laid out, comes from the product being presented.

Token values live in `tokens.css` (Tailwind v4 `@theme`) and `tokens.json`; the brand layer lives in each site's `styles/brand.css`, generated by `set_brand`. If this document and `tokens.css` disagree, `tokens.css` wins.

---

## 1. Principles

1. **Centred, contained, calm.** Every section's content sits in a centred container with even margins. Backgrounds may run edge to edge; text, cards and visuals never do.
2. **The brand leads, the system supports.** One brand colour (and its generated scale) carries identity. Neutrals do the rest. There is no house colour.
3. **One primary action per view.** The accent fill is reserved for the main call to action and a few deliberate highlights.
4. **Show the product's own things.** Visuals depict what the customer actually gets: screens, documents, schedules, prices, results.
5. **Rhythm through tone.** Alternate light sections with occasional tinted, dark or brand bands. Never two dark bands in a row.
6. **Numbers over adjectives.** Real figures, set large, with short captions.

---

## 2. Layout and the centred container

Content never stretches across the full screen width. Each section is a full-width band (for its background) holding one centred container.

| Container | Max width | Use |
|---|---|---|
| `container-page` | 76rem (1216px) | Default for every section |
| `container-wide` | 86rem (1376px) | Large visuals, galleries, bento grids |
| `container-narrow` | 48rem (768px) | Editorial copy, FAQs, forms |

All three are `margin-inline: auto` with 20px side padding on mobile and 32px from 768px. `<Section width="page|wide|narrow">` applies them for you. Inside a container, limit line length further with `max-w-prose` (42rem), `max-w-lede` (38rem, intro paragraphs) and `max-w-headline` (52rem, the H1).

- Grid: 12 columns on desktop (`lg:grid-cols-12`), gaps of 24–48px (`gap-6` to `gap-12`). Asymmetric splits (5/7, 4/8, 6/5 with an empty column) read as designed; use them.
- Vertical rhythm: `section-y` (72px mobile, 112px desktop) between sections; `section-y-tight` for bands like logos or figures; `section-gap` between a section intro and its content.
- Breakpoints: `sm` 640, `md` 768, `lg` 1024, `xl` 1280. Design at 1440 and 390; every layout collapses to one column below `lg` unless it is a deliberate scroller.
- Nav and footer use `container-page` too, so edges line up down the page.

## 3. Colour

### Brand (per site, from `set_brand`)

| Token | Meaning |
|---|---|
| `brand-50 … brand-950` | 11-step scale generated from the brand's primary colour (OKLCH). The primary sits at its closest stop. |
| `second-50 … second-900` | Scale from the secondary colour (or a neighbouring hue) for charts and occasional variety. |
| `accent` / `accent-hover` | Primary button fill and its hover. Contrast-checked against `on-accent`. |
| `on-accent` | Label colour on the accent (white or ink, whichever passes 4.5:1). |
| `accent-soft` / `accent-line` | Brand tint for soft backgrounds and its border. |
| `accent-text` | Brand colour for text and links on light backgrounds (a darker stop when the brand colour is light). |
| `inverse` | Dark brand colour for dark sections (the brand's own dark, or a deep shade of the primary). |
| `canvas`, `surface`, `subtle` (optional) | When the brand uses an off-white or tinted page, `set_brand` replaces the white canvas and its two neutral steps; cards stay white. |

Rules: the brand colour comes from the brand (brief, logo, existing site). If no colour is known, choose one that fits the category and personality and record the choice. Never default to blue for a brand that is not blue. Light or neon brand colours are fine: `set_brand` keeps text and labels readable.

### Neutrals (fixed)

| Token | Value | Use |
|---|---|---|
| `canvas` | `#FFFFFF` | Page background |
| `surface` | `#F6F6F4` | Alternate section background, soft cards |
| `subtle` | `#EDEDEA` | Wells, tracks, inactive fills |
| `line` / `line-strong` | `#E2E2DE` / `#C9C9C3` | Borders and dividers |
| `ink` / `ink-soft` | `#16171A` / `#33353B` | Headlines / strong body |
| `muted` / `faint` | `#5F626A` / `#8E9198` | Body copy / meta |

### Semantic, tone-aware colours (prefer these in sections)

`fg`, `fg-soft`, `fg-muted`, `fg-faint`, `border`, `border-strong`, `card`, `card-soft`, `link`. They resolve to the right values on light, dark and accent sections, so one component works on any tone. Status: `success`, `warning`, `danger` (+ `-soft`).

### Using colour

- Accent fill: the primary button, the selected state of controls, at most one emphasised tile or figure per section.
- Tints (`brand-50/100`, `accent-soft`): soft section backgrounds, highlighted cards, icon tiles.
- Dark (`inverse`, `brand-deep`): up to three bands per page for weight (a manifesto, specs, the closing call to action). Never adjacent.
- Gradients only through the provided backgrounds: `bg-brand-fade`, `bg-brand-mesh`, `bg-brand-deep`, `bg-inverse-glow`, plus `bg-grid` and `bg-dots` textures and `scrim` over photos. Simple two-stop gradients from brand tokens (`from-brand-100 to-canvas`) are allowed for visuals.
- No raw hex or rgb values in components. No default Tailwind palette (it is switched off).

## 4. Typography

Fonts are chosen per brand with `set_brand` from a self-hosted set: Inter, Manrope, DM Sans, Plus Jakarta Sans, Space Grotesk, IBM Plex Sans, Outfit, Instrument Sans (sans); Fraunces, Source Serif 4, Crimson Pro (serif). `font-display` is for headings, `font-sans` for everything else, `font-accent` for an optional third face (quotes, a highlighted word), `font-mono` for code and data.

| Token | Size / line height | Weight | Use |
|---|---|---|---|
| `text-hero` | 72 / 1.02, −3.5% | heading weight | H1 on desktop |
| `text-display` | 56 / 1.05, −3% | heading weight | H1 on mobile, big statements |
| `text-title` | 40 / 1.1, −2.5% | heading weight | Section titles (H2) |
| `text-heading` | 28 / 1.2, −2% | heading weight | Block titles, figures, quotes |
| `text-subheading` | 20 / 1.35 | heading weight | Card and item titles |
| `text-lead` | 20 / 1.55 | 400 | Intro paragraphs |
| `text-body` | 17 / 1.6 | 400 | Body copy |
| `text-label` | 15 / 1.3 | 500 | Buttons, labels, names |
| `text-small` | 14 / 1.5 | 400 | Captions, notes |
| `text-kicker` | 13 / 1.2, +8%, uppercase | 600 | Kicker above titles (`kicker` utility) |
| `text-micro` | 12 / 1.4 | 500 | Meta, tags, badges |

- Heading weight is a brand choice (`--heading-weight`, 400–700, default 600). Weights available: `font-normal`, `font-medium`, `font-semibold`, `font-bold`.
- One H1 per page. Headlines are short, sentence case, `text-balance`; paragraphs `text-pretty`.
- Line height and tracking come with the size token; don't add `leading-*` or `tracking-*`.
- Figures use `tabular-nums`.

## 5. Shape and elevation

Corners come from the brand's roundness: `sharp`, `soft` (default) or `round` (pill buttons).

| Token | sharp | soft | round | Use |
|---|---|---|---|---|
| `rounded-sm` | 2 | 6 | 10 | Chips, small controls |
| `rounded-md` | 4 | 10 | 16 | Inputs, icon tiles, small cards |
| `rounded-lg` | 6 | 16 | 24 | Cards |
| `rounded-xl` | 10 | 24 | 32 | Panels, large visuals, banners |
| `rounded-button` | 4 | 10 | pill | Buttons |
| `rounded-full` | — | — | — | Avatars, dots, pills |

Shadows: `shadow-sm` (buttons, small raised items), `shadow-md` (raised cards, popovers), `shadow-lg` (one floating product visual per section), `shadow-brand` (a glow under one brand-coloured element). Most cards are flat with a 1px `border`.

## 6. Section tones

Set on `<Section tone="…">`; everything inside adapts through the semantic colours.

| Tone | Look | Good for |
|---|---|---|
| `canvas` | White | Default |
| `surface` | Warm off-white | Alternating sections |
| `brand-fade` | Brand tint fading to white | Heroes, openers |
| `brand-soft` | Flat brand tint | Quotes, figures |
| `brand-mesh` | Soft brand mesh | One visual-led band |
| `grid` / `dots` | White with a fine texture | Technical products, heroes |
| `inverse` | Dark brand colour | Manifesto, specs, contrast |
| `inverse-glow` | Dark with brand glow | Launch heroes, closing CTA |
| `brand-deep` | Deep brand colour | Statement bands |
| `accent` | Full brand colour | One short band at most |

Inside a dark band, a white card needs `tone-light` (the `Card`, `BrowserFrame` and `DocSheet` primitives already do this where needed).

## 7. Icons, imagery and product visuals

- Icons: the curated Lucide set via `<Icon name="…" />` and `<IconTile name="…" />`, 1.75 stroke, sized 16–24px. Icons label, they don't decorate.
- Product visuals are built from primitives (`BrowserFrame`, `DocSheet`, `ChatBubble`, `KeyValues`, cards, tables) with content from the brief, or real screenshots supplied as assets.
- Photos: only supplied ones, in `Media` with `rounded-xl`; `scrim` when text sits on top.
- Missing material (logos, quotes, photos, metrics) is shown as `<Placeholder label="…" />`, never invented.

---

## 8. Interaction and motion

- Every interactive element works: tabs, carousels, toggles, filters, accordions, dialogs, sliders and forms. Use the primitives in `components/ui/interactive`, which follow the conventions in COMPONENTS.md and pass `test_interactions`.
- Keyboard: everything reachable by Tab, visible focus ring (2px accent), arrow keys inside tab lists and steppers, Escape closes dialogs.
- Motion is short and functional: 200ms colour transitions (`ease-standard`), `animate-fade-up` for a reveal at most once per section, carousel autoplay only when it pauses on hover and focus. All motion respects `prefers-reduced-motion`.
- Hover states: buttons darken (`accent-hover`), cards may lift their border to `border-strong`; nothing jumps or scales more than 2%.

---

## 9. Copy voice

Short declaratives in plain words. Lead with the outcome, then the how. Numbers where the brief has them. Verb + noun CTAs ("Book a demo", "Get the guide"). Sentence case everywhere; statements end with a period. No exclamation marks, no buzzwords, no emoji.

---

## 10. Don'ts

- Content running edge to edge on wide screens.
- A default blue (or any colour) that isn't the brand's.
- Raw colours, arbitrary values (`text-[#…]`, `rounded-[13px]`), inline visual styles.
- More than one H1; headings skipped for size.
- Fake interactivity: a slider that changes nothing, tabs that don't switch, a form that goes nowhere.
- Invented logos, testimonials, people or numbers.
