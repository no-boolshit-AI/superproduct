# editorial-chart-highlight — A Simple Chart → The One Category That Matters

**intent**: Data as an editorial figure: a title in the display face, a source line in mono, a few bars (or stacked bars) growing on a drafting grid, the legend in mono; then the highlighter marks the one category the explanation is about. Built on `editorial-kit`.

**roles served**

- Social_proof / evidence: a trend or a share from a cited source in the brief.
- Benefit_highlight: the change over time.

**duration**: 5–7 s.

**shot structure**

```
Scene 1 (0.0–~1.0s): paper ground + grid; [the chart title] rises; [the source line] (mono, small) under it.
Scene 2 (~0.8–~3.0s): [2–5 bars] grow from the baseline left to right with a stagger; values in mono on top.
Scene 3 (~3.0–~4.0s): the highlighter marks [the category] in the legend (or a bar turns the field colour
  while the others stay muted).
Scene 4 (~4.0s–end): held read.
```

**signature move**: a quiet, sourced chart — and one category lit up.

**motion vocabulary**: rise, grow from bottom with stagger, highlighter.

**rule mapping**

- bars, grid, labels → `rules/editorial-graphics.md`
- highlighter → `rules/editorial-callouts.md`
- scaffold → `rules/editorial-kit.md`

**layout (4:5 / 9:16)**: title upper 15%, chart 15–70%, legend below the chart; labels ≥ 28 px. **16:9**: chart left 60%, legend right.

**stillness note**: hold ≥ 2 s; never animate values after they land. Data comes from the brief only, with its source.
