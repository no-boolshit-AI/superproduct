# collage-clipping-highlight — Clipping Lands → Strike the Wrong Words → Circle the Right Ones

**intent**: The argument frame. A torn clipping lands carrying the claim; a hand annotates it like an editor — strikes the phrase that is wrong, circles or highlights the phrase that is right, and pins a counter-note with the correction. The annotation IS the message. Built on `collage-kit`.

**roles served**

- Problem: the status quo printed, then struck out ("~~demo data~~ → your team's real workflows").
- Key_Feature / Benefits: the product's promise printed, its key phrase highlighted, a margin note adds the proof that exists in the brief.
- Takeaway: one sentence, one circled word.

**duration**: 4.5–6.5 s.

**shot structure**

```
Scene 1 (0.0–~0.6s): paper ground; [the clipping] — a torn sheet with an optional FIG./kicker
  label, [the statement] in the display face, and greeked text lines below — slaps in, centred
  upper half, tilt ±1–3°.
Scene 2 (~0.6–~2.4s): held read of [the statement] (≥ 1.2 s; the viewer must finish it).
Scene 3 (~2.4–~3.6s): the annotation pass, one stroke per beat: strike-through on [the wrong
  phrase] → loop or highlighter on [the right phrase] → an arrow from the margin.
Scene 4 (~3.6–~4.4s): [the counter-note] — a smaller torn strip, a sticker, or a stamp with
  [the correction / qualifier] — slaps on at the arrow's end; tape pins it.
Scene 5 (~4.4s–end): held read; boil; slow push.
```

**signature move**: the editor's pass — strike, then circle/highlight, then the note the arrow points at. Strokes draw on twos, in reading order.

**motion vocabulary**: slap, held read, marker draw (strike, loop, arrow), highlighter, note slap + tape, boil, push-in.

**rule mapping**

- clipping + note entrances → `rules/collage-cutout-slap.md`
- torn clipping / note → `rules/collage-paper-tear.md`
- strike / loop / arrow / highlighter / tape / stamp → `rules/collage-marker-annotate.md`
- boil, on twos → `rules/collage-stop-motion-boil.md`
- push-in → `rules/collage-camera.md`
- scaffold → `rules/collage-kit.md`

**layout (4:5 / 9:16)**: clipping ~85% wide in the upper 60%; the counter-note overlaps its lower-right corner or sits below it; arrows run from the note to the phrase; bottom 17% clear.

**content rule**: the clipping's readable words come from the brief; its body text is greeked (`cg-greek`) — never invent quotes, sources, mastheads or dates.
