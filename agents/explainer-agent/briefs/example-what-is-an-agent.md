# What an AI agent actually is

Audience: founders and team leads at small companies who keep hearing "agents" and can't tell them from chatbots.

The question: what does an AI agent do that a chatbot doesn't?
The one message: an agent is a model that uses tools in a loop until a job is done, and you decide which tools it gets.

Beats:
- Hook: everyone sells "AI agents"; most are chatbots with a new name.
- A chatbot answers. An agent acts: it reads, decides, uses a tool, checks the result, and goes again.
- Three parts: a model, the tools it may use, and a loop with a clear stop.
- What stays yours: which tools and data it gets, and where a person approves.
- Close: start with one task you already do every week.

45 seconds, no narration: the on-screen text carries it.
