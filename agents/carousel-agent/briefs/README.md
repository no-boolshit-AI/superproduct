# briefs/

Not for your briefs: they live in the workspace (`../../../workspace/briefs/`, see
[`templates/workspace/README.md`](../../../templates/workspace/README.md)), next to the product folder and the results,
and this folder is git-ignored apart from this file. Run the agent with `--file ../../workspace/briefs/<brief>.md`.
The product's facts, voice and brand come from the product folder, so a brief only needs what is specific to the post.
